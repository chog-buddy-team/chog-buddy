# Chat Box Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The owner can talk to their Chog. They click it, or press Ctrl+Shift+Space, type into a small box above it, and the reply streams into the speech bubble in that Chog's voice. Replies come from a local Ollama model or from the Gemini free tier, using the owner's own key.

**Architecture:**
- **Main process:** owns the LLM calls. Two small providers, `ollama.ts` and `gemini.ts`, share one streaming interface. A pure `ChatSession` picks a provider, keeps the history and maps errors into in-character lines. A pure prompt builder gives the Chog its voice.
- **Renderer:** shows an input above the Pet and streams tokens into the bubble.
- **Window and keys:** the window grows upward while chat is open and only becomes focusable then. The Gemini key is stored encrypted with Electron `safeStorage`.

**Tech Stack:** Electron, TypeScript, vitest, Node `fetch` streaming. No new dependencies.

**Spec:** this plan carries its own design, which was approved in chat on 2026-10-09 and summarized under "Design" below. Background is in `docs/designs/chog-buddy.md` (Interaction: "small chat box") and `CONTEXT.md`. ADR 0001 governs privacy.

**Base:** branch `chat-box`, cut from `sprite-kit`.

## Design (approved 2026-10-09)
- **Open:** click the Chog, or press the global hotkey `Ctrl+Shift+Space`. An input appears above the Chog. Enter sends, Esc closes. Poking moves to the tray item only.
- **Reply:** streams into the speech bubble while the Pet plays the talk animation.
- **Provider order:** Ollama first, if it is running at `http://127.0.0.1:11434`. Otherwise Gemini, if the owner has saved a key. The tray can force one or the other.
- **Gemini key:** the owner pastes it via the tray item "Set Gemini key…", which reuses the chat input in password mode. It is stored encrypted with `safeStorage`. Never ship our own key.
- **Context sent:** Chog name, Archetype voice, today's Category minutes, and the last 20 messages. Never window titles, app names or message content from other apps (ADR 0001).
- **History:** the last 20 messages, kept in memory only and cleared on quit.
- **No provider:** the Chog says, in character, to install Ollama or add a Gemini key from the tray.
- **Tray:** "Chat AI" submenu with Auto, Ollama and Gemini; an Ollama model list read from `/api/tags`; "Set Gemini key…" and "Clear Gemini key"; and a note that the Gemini free tier may use chats for training.

## Global Constraints
- No new npm dependencies. $0. Ollama is optional and never bundled.
- Hotkey `Control+Shift+Space`. History cap 20 messages. User message cap 500 characters.
- Ollama base URL `http://127.0.0.1:11434`. Default Ollama model `llama3.2`. Gemini model `gemini-2.5-flash`. Endpoint `https://generativelanguage.googleapis.com/v1beta/models/<model>:streamGenerateContent?alt=sse`, with the key in the `x-goog-api-key` header and never in the URL.
- Only Category minutes may leave the machine. No titles, no app names (ADR 0001).
- The Gemini key is never logged, never sent to the renderer after it is saved, and stored only `safeStorage`-encrypted.
- Commit messages end with a blank line, then `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus
1. **Ollama is not installed or not running:** the availability check must give up within 1.5 s, and the Gemini fallback or the "no provider" line must appear. The chat must never hang. Tested in Task 2 and Task 3.
2. **A bad Gemini key, a quota error (429) or no network:** the Chog replies with an in-character error line, and the raw API error never shows in the bubble. Tested in Task 3.
3. **A stream that ends mid-JSON, or a split SSE/NDJSON chunk:** the parser must buffer partial lines and lose no tokens. Tested in Task 2.
4. **Very long or empty input, or input that is only whitespace:** empty input is ignored, and input over 500 characters is cut to 500. Tested in Task 3.
5. **Chat open while dragging or walking:** walking pauses while chat is open, and closing chat restores the window height on the same display. This is verified manually in Task 4.

```ts
/** Split a streamed body into lines, buffering partial lines across chunks. */
export async function readLines(body: ReadableStream<Uint8Array>, onLine: (line: string) => void): Promise<void> {
  const reader = body.getReader();
  const dec = new TextDecoder();
  let buf = '';
  for (;;) {
    const { done, value } = await reader.read();
    if (done) break;
    buf += dec.decode(value, { stream: true });
    let i: number;
    while ((i = buf.indexOf('\n')) >= 0) {
      onLine(buf.slice(0, i).replace(/\r$/, ''));
      buf = buf.slice(i + 1);
    }
  }
  buf += dec.decode();
  if (buf.trim()) onLine(buf);
}
```

`app/src/main/llm/ollama.ts`:
```ts
import { readLines } from './stream';
import { ProviderError, type ChatMessage, type ChatProvider } from './types';

export function createOllama(opts: { model: string; baseUrl?: string; fetchImpl?: typeof fetch }): ChatProvider & { listModels(): Promise<string[]> } {
  const base = opts.baseUrl ?? 'http://127.0.0.1:11434';
  const f = opts.fetchImpl ?? fetch;

  async function listModels(): Promise<string[]> {
    const res = await f(`${base}/api/tags`, { signal: AbortSignal.timeout(1500) });
    if (!res.ok) return [];
    const json = (await res.json()) as { models?: Array<{ name?: string }> };
    return (json.models ?? []).map((m) => m.name).filter((n): n is string => typeof n === 'string');
  }

  return {
    id: 'ollama',
    listModels,
    async available() {
      try {
        return (await listModels()).length > 0;
      } catch {
        return false;
      }
    },
    async stream(system: string, history: ChatMessage[], onToken: (t: string) => void) {
      let res: Response;
      try {
        res = await f(`${base}/api/chat`, {
          method: 'POST',
          headers: { 'content-type': 'application/json' },
          body: JSON.stringify({ model: opts.model, stream: true, messages: [{ role: 'system', content: system }, ...history] }),
          signal: AbortSignal.timeout(60_000),
        });
      } catch (e) {
        throw new ProviderError(`ollama unreachable: ${(e as Error).message}`, 'network');
      }
      if (!res.ok || !res.body) throw new ProviderError(`ollama HTTP ${res.status}`, 'bad-response');
      let out = '';
      await readLines(res.body, (line) => {
        if (!line.trim()) return;
        try {
          const t = (JSON.parse(line) as { message?: { content?: string } }).message?.content;
          if (t) {
            out += t;
            onToken(t);
          }
        } catch {
          // ignore a malformed line rather than aborting the reply
        }
      });
      return out;
    },
  };
}
```

`app/src/main/llm/gemini.ts`:
```ts
import { readLines } from './stream';
import { ProviderError, type ChatMessage, type ChatProvider } from './types';

export function createGemini(opts: { apiKey: string | null; model?: string; fetchImpl?: typeof fetch }): ChatProvider {
  const f = opts.fetchImpl ?? fetch;
  const model = opts.model ?? 'gemini-2.5-flash';
  return {
    id: 'gemini',
    async available() {
      return !!opts.apiKey;
    },
    async stream(system: string, history: ChatMessage[], onToken: (t: string) => void) {
      if (!opts.apiKey) throw new ProviderError('no gemini key', 'auth');
      let res: Response;
      try {
        res = await f(`https://generativelanguage.googleapis.com/v1beta/models/${model}:streamGenerateContent?alt=sse`, {
          method: 'POST',
          headers: { 'content-type': 'application/json', 'x-goog-api-key': opts.apiKey },
          body: JSON.stringify({
            systemInstruction: { parts: [{ text: system }] },
            contents: history.map((m) => ({ role: m.role === 'assistant' ? 'model' : 'user', parts: [{ text: m.content }] })),
          }),
          signal: AbortSignal.timeout(60_000),
        });
      } catch (e) {
        throw new ProviderError(`gemini unreachable: ${(e as Error).message}`, 'network');
      }
      if (res.status === 429) throw new ProviderError('gemini quota', 'quota');
      if ([400, 401, 403].includes(res.status)) throw new ProviderError(`gemini auth ${res.status}`, 'auth');
      if (!res.ok || !res.body) throw new ProviderError(`gemini HTTP ${res.status}`, 'bad-response');
      let out = '';
      await readLines(res.body, (line) => {
        if (!line.startsWith('data:')) return;
        try {
          const json = JSON.parse(line.slice(5).trim()) as { candidates?: Array<{ content?: { parts?: Array<{ text?: string }> } }> };
          for (const p of json.candidates?.[0]?.content?.parts ?? []) {
            if (p.text) {
              out += p.text;
              onToken(p.text);
            }
          }
        } catch {
          // partial or non-JSON event: skip
        }
      });
      return out;
    },
  };
}
```

`app/src/main/llm/session.ts`:
```ts
import { ProviderError, type ChatMessage, type ChatProvider } from './types';

export type ProviderPref = 'auto' | 'ollama' | 'gemini';
export const HISTORY_CAP = 20;
export const MAX_INPUT = 500;

const LINES: Record<ProviderError['kind'] | 'none', string> = {
  none: "I can't think yet! Install Ollama, or add a Gemini key from my tray menu.",
  auth: "My Gemini key isn't working. Set a new one from the tray menu?",
  quota: "I'm all talked out for now (free tier limit). Try again in a bit!",
  network: "I can't reach my brain right now. Is the internet (or Ollama) on?",
  'bad-response': 'Brain glitch. Say that again?',
};

export const errorLine = (kind: ProviderError['kind'] | 'none') => LINES[kind];

export async function pickProvider(pref: ProviderPref, providers: ChatProvider[]): Promise<ChatProvider | null> {
  const order = pref === 'auto' ? ['ollama', 'gemini'] : [pref];
  for (const id of order) {
    const p = providers.find((x) => x.id === id);
    if (p && (await p.available())) return p;
  }
  return null;
}

export class ChatSession {
  history: ChatMessage[] = [];

  constructor(
    private getProviders: () => ChatProvider[],
    private getPref: () => ProviderPref,
    private getSystem: () => string,
  ) {}

  async send(text: string, onToken: (t: string) => void): Promise<{ reply: string; provider: ChatProvider['id'] | null; failed: boolean }> {
    const content = text.trim().slice(0, MAX_INPUT);
    if (!content) return { reply: '', provider: null, failed: false };
    const provider = await pickProvider(this.getPref(), this.getProviders());
    if (!provider) return { reply: errorLine('none'), provider: null, failed: true };
    const turn: ChatMessage[] = [...this.history, { role: 'user', content }];
    try {
      const reply = await provider.stream(this.getSystem(), turn, onToken);
      this.history = [...turn, { role: 'assistant' as const, content: reply }].slice(-HISTORY_CAP);
      return { reply, provider: provider.id, failed: false };
    } catch (e) {
      const kind = e instanceof ProviderError ? e.kind : 'bad-response';
      return { reply: errorLine(kind), provider: provider.id, failed: true };
    }
  }
}
```
