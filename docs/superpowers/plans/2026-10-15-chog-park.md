# Chog Park Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A public web page, `/park`, showing every active Chog as a card, plus a daily focus leaderboard and a link to the onchain Soul contract. The card shows the Soul axes, level, Archetype and a public mood line.

**Architecture:**
- `web/lib/park.ts` holds a pure `buildPark()`, which turns DB rows plus Chog metadata into cards and a leaderboard, and a pure `moodLine()`. Both are unit-tested.
- A thin `loadPark()` runs one SQL query and fetches metadata.
- `web/app/park/page.tsx` is a server component with `revalidate = 300`, so the page, DB and IPFS work run at most every 5 minutes.
- The default Next.js landing page at `/` is replaced by a small Chog Buddy page linking to the Park.

**Tech Stack:** Next.js 16 App Router (server components), Neon serverless SQL, `@chog/core`, CSS modules, vitest. No new dependencies.

**Spec:** `docs/designs/chog-buddy.md:105`:
> **Chog Park:** web grid of active Chogs with soul axes, level, public mood line, daily focus leaderboard, link to soul contract entry. No diary content.

Also `CONTEXT.md` ("Chog Park").

## Global Constraints
- No diary or chat content, ever. No owner wallet addresses on the page.
- Per Chog, only these appear:
  - Soul axes and level (already public onchain)
  - Archetype, name and image (public NFT metadata)
  - one mood line derived from the latest day's top Category
  - focus minutes (`coding + design`)
  - No other Category breakdown.
- "Active" means the Chog has an `activity` row in the last 7 days. The demo Chog (owner `'demo'`) is labelled **Demo**.
- $0. No new dependencies. Images load with a plain `<img>` from the Pinata gateway (`ipfsToHttp`).
- Soul contract link: `https://testnet.monadexplorer.com/address/${process.env.SOUL_CONTRACT}`. Omit the link when the env var is unset.
- Commits end with a blank line, then `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus
- A Chog with activity but no Soul row yet (the cron lags 2 days): the card shows "Soul forming", with no axes or level, and no crash (Task 1 test).
- A metadata fetch fails for one token: that card falls back to name `Chog #id`, with no image and no Archetype, and the rest still render (Task 1 test).
- No active Chogs at all: the page shows an empty state instead of an empty grid (Task 2).
- Corrupt `totals` JSON in a row: the Chog still shows, with 0 focus minutes and a neutral mood (Task 1 test).
- The leaderboard only counts the latest day, and only when it is today or yesterday on server time. Stale Chogs are left off the board but keep their card (Task 1 test).

```ts
import { ARCHETYPES, fetchChogMetadata, ipfsToHttp, parseDailyTotals, pickArchetype, type ArchetypeId, type Category, type DailyTotals } from '@chog/core';
import { sql } from './db';

export type ParkRow = { tokenId: number; day: string; totals: unknown; demo: boolean; soul: { nightOwl: number; grinder: number; social: number; creator: number; level: number } | null };
export type ParkMeta = { name: string; image: string | null; archetype: ArchetypeId | null };
export type ParkChog = { tokenId: number; name: string; image: string | null; archetypeName: string | null; demo: boolean; soul: ParkRow['soul']; mood: string; focusMinutes: number; day: string };

const ACTIVE: Category[] = ['coding', 'design', 'chat', 'browsing', 'video', 'meeting', 'other'];
const MOOD: Record<ArchetypeId, Partial<Record<Category, string>> & { none: string }> = {
  hype: { coding: 'CODING SPREE! Unstoppable!', design: 'Making beautiful things!!', chat: 'Social butterfly mode!', video: 'Movie marathon energy!', meeting: 'Crushing meetings!', none: 'Charging up for tomorrow!' },
  grump: { coding: 'Watched them code. Fine. It was fine.', design: 'Pixels. So many pixels.', chat: 'So much talking.', video: 'Videos again. Riveting.', meeting: 'Meetings. Ugh.', none: 'Quiet. Finally.' },
  lazySage: { coding: 'The code flows like a river.', design: 'Shapes, colours, stillness.', chat: 'Many words, one silence.', video: 'Watching shadows on a screen.', meeting: 'Circles of talk.', none: 'Resting. As one should.' },
  chaos: { coding: 'Typed SO many semicolons. Maybe.', design: 'Drew a duck. Probably a duck.', chat: 'Gossip goblin hours!', video: 'Ate the popcorn. All of it.', meeting: 'Unmuted at the worst time.', none: 'Hiding in the recycle bin.' },
  sweetheart: { coding: 'So proud of all that coding!', design: 'Made something lovely today.', chat: 'Caught up with friends!', video: 'Cozy video time.', meeting: 'Brave through the meetings!', none: 'Taking it easy. Good.' },
};

export function moodLine(archetype: ArchetypeId | null, t: DailyTotals | null): string {
  const a = archetype ?? 'sweetheart';
  if (!t) return MOOD[a].none;
  const [top, min] = ACTIVE.map((c) => [c, t.minutes[c]] as const).sort((x, y) => y[1] - x[1])[0];
  return (min >= 1 && MOOD[a][top]) || MOOD[a].none;
}

const dayBefore = (d: string) => new Date(Date.parse(`${d}T12:00:00Z`) - 86_400_000).toISOString().slice(0, 10);

export function buildPark(rows: ParkRow[], metas: Map<number, ParkMeta>, today: string) {
  const fresh = new Set([today, dayBefore(today)]);
  const chogs: ParkChog[] = rows.map((r) => {
    let t: DailyTotals | null = null;
    try { t = parseDailyTotals(r.totals); } catch { t = null; }
    const m = metas.get(r.tokenId);
    return {
      tokenId: r.tokenId,
      name: m?.name ?? `Chog #${r.tokenId}`,
      image: m?.image ?? null,
      archetypeName: m?.archetype ? ARCHETYPES[m.archetype].name : null,
      demo: r.demo,
      soul: r.soul,
      mood: moodLine(m?.archetype ?? null, t),
      focusMinutes: t ? Math.round(t.minutes.coding + t.minutes.design) : 0,
      day: r.day,
    };
  });
  chogs.sort((a, b) => (b.soul?.level ?? -1) - (a.soul?.level ?? -1) || a.tokenId - b.tokenId);
  const leaderboard = chogs
    .filter((c) => fresh.has(c.day) && c.focusMinutes > 0)
    .sort((a, b) => b.focusMinutes - a.focusMinutes || a.tokenId - b.tokenId)
    .slice(0, 10)
    .map(({ tokenId, name, focusMinutes }) => ({ tokenId, name, focusMinutes }));
  return { chogs, leaderboard };
}

// ponytail: one metadata fetch per active Chog every 5 min (page revalidate); cache metadata in the DB if the Park grows past ~200 Chogs.
export async function loadPark() {
  const rows = (await sql`
    select distinct on (a.token_id) a.token_id, to_char(a.day, 'YYYY-MM-DD') as day, a.totals, a.owner = 'demo' as demo,
      s.night_owl, s.grinder, s.social, s.creator, s.level, to_char(current_date, 'YYYY-MM-DD') as today
    from activity a left join souls s on s.token_id = a.token_id
    where a.day >= current_date - 7
    order by a.token_id, a.day desc
    limit 300`) as Array<Record<string, any>>;
  const today = rows[0]?.today ?? new Date().toISOString().slice(0, 10);
  const parkRows: ParkRow[] = rows.map((r) => ({
    tokenId: r.token_id, day: r.day, totals: r.totals, demo: r.demo,
    soul: r.level == null ? null : { nightOwl: r.night_owl, grinder: r.grinder, social: r.social, creator: r.creator, level: r.level },
  }));
  const metas = new Map<number, ParkMeta>();
  await Promise.allSettled(parkRows.map(async (r) => {
    const m = await fetchChogMetadata(r.tokenId);
    metas.set(r.tokenId, { name: m.name, image: m.image ? ipfsToHttp(m.image) : null, archetype: pickArchetype(m) });
  }));
  return buildPark(parkRows, metas, today);
}

import { loadPark } from '@/lib/park';
import s from './park.module.css';

export const revalidate = 300; // rebuild at most every 5 minutes
export const metadata = { title: 'Chog Park', description: 'Every active Chog Buddy, its onchain Soul and today’s focus leaderboard.' };

const AXES = [['nightOwl', 'Night owl'], ['grinder', 'Grinder'], ['social', 'Social'], ['creator', 'Creator']] as const;

export default async function Park() {
  let park: Awaited<ReturnType<typeof loadPark>> | null = null;
  try { park = await loadPark(); } catch { park = null; }
  const contract = process.env.SOUL_CONTRACT;
  return (
    <main className={s.main}>
      <header className={s.header}>
        <h1>Chog Park</h1>
        <p>Every Chog living on someone’s desktop. Souls grow onchain from real days; diaries stay private.</p>
        {contract && <a href={`https://testnet.monadexplorer.com/address/${contract}`} target="_blank" rel="noopener noreferrer">ChogSoul contract on Monad testnet ↗</a>}
      </header>
      {!park ? <p className={s.empty}>The Park is closed for a moment. Try again soon.</p> : (
        <>
          <section className={s.board} aria-labelledby="lb">
            <h2 id="lb">Today’s focus leaderboard</h2>
            {park.leaderboard.length === 0 ? <p className={s.empty}>No focus minutes yet today.</p> : (
              <ol>{park.leaderboard.map((l) => <li key={l.tokenId}><span>{l.name}</span><b>{l.focusMinutes} min</b></li>)}</ol>
            )}
          </section>
          {park.chogs.length === 0 ? <p className={s.empty}>No Chogs in the Park yet. Install Chog Buddy and yours will show up here.</p> : (
            <ul className={s.grid}>
              {park.chogs.map((c) => (
                <li key={c.tokenId} className={s.card}>
                  {c.image ? <img src={c.image} alt={c.name} loading="lazy" width={96} height={96} /> : <div className={s.noimg} aria-hidden />}
                  <h3>{c.name}{c.demo && <span className={s.demo}>Demo</span>}</h3>
                  {c.archetypeName && <p className={s.arch}>{c.archetypeName}</p>}
                  <p className={s.mood}>“{c.mood}”</p>
                  {c.soul ? (
                    <>
                      <p className={s.level}>Level {c.soul.level}</p>
                      {AXES.map(([k, label]) => (
                        <div key={k} className={s.axis}>
                          <span>{label}</span>
                          <meter min={0} max={100} value={c.soul![k]} aria-label={`${label} ${c.soul![k]} of 100`} />
                        </div>
                      ))}
                    </>
                  ) : <p className={s.level}>Soul forming…</p>}
                </li>
              ))}
            </ul>
          )}
        </>
      )}
    </main>
  );
}
```
