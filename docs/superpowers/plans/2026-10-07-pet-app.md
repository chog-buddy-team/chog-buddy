# Chog Buddy Pet App Implementation Plan (Track A: frontend owner)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A working local desktop Pet (Mac + Windows). It loads a Chog by token ID, derives its Archetype from Traits, walks the screen, perches on windows, can be dragged, and reacts to Activity with templated lines. It needs no server.

**Architecture:** An npm-workspaces monorepo. `packages/core` holds pure, shared domain logic (types, Categorizer, Archetype, chain/metadata helpers) used by both the app and the web backend. `app/` is Electron: the main process owns window movement, Activity polling and Reactions; the renderer only draws the sprite and speech bubble, and forwards drag/click. Pure logic is unit-tested with vitest; Electron wiring is verified manually.

**Tech Stack:** Node 24, TypeScript, npm workspaces, vitest, viem, Electron, esbuild, get-windows, electron-builder.

**Spec:** `docs/designs/chog-buddy.md` (plus `CONTEXT.md` for vocabulary, `docs/adr/`).

**Companion plan:** `docs/superpowers/plans/2026-10-07-soul-backend.md` (Track B, teammate). Track B's web tasks import `@chog/core`, so **merge Task 1 and Task 2 of this plan on day 1**.

## Global Constraints

- Budget $0: free tiers only, unsigned installers.
- Chog Genesis contract: `0xc96d31F8626c6D03Fae5dCD3d61e3FB9F4a73763` on Monad mainnet, token IDs 1-1969, not enumerable.
- Always resolve metadata via `tokenURI` (token IDs are shuffled vs metadata files). Gateway `https://chog-genesis.mypinata.cloud/ipfs/`.
- Only Categories and durations ever leave the machine (ADR 0001). Window titles are not read in v1.
- At least 3 minutes between unprompted Reactions.
- Pet sprite window is small (160x190) and moved around. Never a full-screen overlay.
- Use the words in `CONTEXT.md` (Chog, Pet, Archetype, Category, Reaction, Trigger, Focus Mode) in code names.

## Review Focus

1. **Token ID outside 1-1969 or not numeric** (bad env var or settings): expect a clear error, not a hang. Test in Task 2.
2. **Metadata/IPFS fetch fails at launch** (offline, gateway down): expect 3 retries then an error box and quit. No zombie process. Verified in Task 6, step 4.
3. **Short app names inside other words** ("arc" in "search", "edge" in "knowledge"): must not misfile. Test in Task 1.
4. **Reaction spam**: several Triggers firing in one poll, or rapid app switching, must still respect the 3-minute cooldown, and suppressed one-time greetings must not be lost forever. Test in Task 3.
5. **Pet leaves the screen**: multi-monitor, display unplugged, or the dragged-to position is off-screen. Expect the Pet clamped back into the nearest display's work area. Test in Task 4 (`clampX`), applied in Task 6.

`packages/core/src/categorize.ts`:

import type { Category } from './types';

export const IDLE_THRESHOLD_SEC = 120;

// Order matters: first match wins. Short names use \b so "arc" doesn't match "search".
const RULES: Array<[Category, RegExp]> = [
  ['meeting', /zoom|\bteams\b|google meet|meet\.google|webex|facetime|gather/i],
  ['coding', /\bcode\b|cursor|xcode|intellij|webstorm|pycharm|android studio|terminal|iterm|warp|ghostty|sublime|\bvim\b|\bzed\b|github|gitlab|stack ?overflow|localhost/i],
  ['design', /figma|sketch|photoshop|illustrator|affinity|blender|canva|procreate|framer/i],
  ['chat', /slack|discord|telegram|whatsapp|\bmessages\b|signal|messenger|wechat/i],
  ['video', /youtube|netflix|twitch|\bvlc\b|\biina\b|prime video|disney\+|tiktok|quicktime/i],
  ['browsing', /chrome|safari|firefox|\barc\b|brave|\bedge\b|opera|x\.com|twitter|reddit/i],
];

export function categorize(app: string, title = '', idleSec = 0): Category {
  if (idleSec >= IDLE_THRESHOLD_SEC) return 'idle';
  // Title first: "YouTube - Chrome" is video, not browsing.
  for (const [category, re] of RULES) if (title && re.test(title)) return category;
  for (const [category, re] of RULES) if (re.test(app)) return category;
  return 'other';
}
```

import type { ArchetypeId, Axes, ChogMetadata } from './types';

export const ARCHETYPES: Record<ArchetypeId, { name: string; base: Axes }> = {
  hype: { name: 'Hype Chog', base: { nightOwl: 50, grinder: 70, social: 70, creator: 50 } },
  grump: { name: 'Grump Chog', base: { nightOwl: 40, grinder: 60, social: 20, creator: 50 } },
  lazySage: { name: 'Lazy Sage', base: { nightOwl: 70, grinder: 20, social: 40, creator: 60 } },
  chaos: { name: 'Chaos Chog', base: { nightOwl: 80, grinder: 40, social: 60, creator: 70 } },
  sweetheart: { name: 'Sweetheart', base: { nightOwl: 40, grinder: 50, social: 80, creator: 40 } },
};

const ORDER: ArchetypeId[] = ['hype', 'grump', 'lazySage', 'chaos', 'sweetheart'];

// Keywords matched (lowercase substring) against real Chog trait values.
const KEYWORDS: Record<ArchetypeId, string[]> = {
  hype: ['happy', 'laser', 'smile', 'green candle', 'fire', 'burning', 'electric', 'gold', 'mog', 'thug', 'coin'],
  grump: ['angry', 'side eye', 'flat', 'grit', 'red candle', 'knife', 'cigar', 'skull', 'smirk'],
  lazySage: ['tired', 'closed', 'drool', 'smoke', 'wind', 'cool', 'visor', 'vr', 'glass', 'mint', 'clean'],
  chaos: ['retard', 'xd', 'clown', 'puke', 'dead', 'radioactive', 'frog', 'fwog', 'pepe', 'vertical', 'multi'],
  sweetheart: ['heart', 'crying', 'tear', 'worried', 'sad', 'rose', 'pink', 'bubblegum', 'lip bite'],
};

const SCORED_TRAITS = new Set(['Eyes', 'Mouth', 'Accessory', 'Aura', 'Base', 'Skin']);

export function pickArchetype(meta: Pick<ChogMetadata, 'tokenId' | 'attributes'>): ArchetypeId {
  const scores = new Map<ArchetypeId, number>(ORDER.map((id) => [id, 0]));
  for (const { trait_type, value } of meta.attributes) {
    if (!SCORED_TRAITS.has(trait_type)) continue;
    const v = value.toLowerCase();
    for (const id of ORDER) for (const kw of KEYWORDS[id]) if (v.includes(kw)) scores.set(id, scores.get(id)! + 1);
  }
  const best = Math.max(...scores.values());
  const tied = ORDER.filter((id) => scores.get(id) === best);
  return tied[meta.tokenId % tied.length];
}
```

`packages/core/src/chain.ts`:
```ts
import { createPublicClient, defineChain, http, parseAbi } from 'viem';
import type { ChogMetadata, Trait } from './types';

export const CHOG_CONTRACT = '0xc96d31F8626c6D03Fae5dCD3d61e3FB9F4a73763' as const;
export const CHOG_SUPPLY = 1969;
export const IPFS_GATEWAY = 'https://chog-genesis.mypinata.cloud/ipfs/';

export const monad = defineChain({
  id: 143,
  name: 'Monad',
  nativeCurrency: { name: 'MON', symbol: 'MON', decimals: 18 },
  rpcUrls: { default: { http: ['https://rpc.monad.xyz'] } },
});

export const monadTestnet = defineChain({
  id: 10143,
  name: 'Monad Testnet',
  nativeCurrency: { name: 'MON', symbol: 'MON', decimals: 18 },
  rpcUrls: { default: { http: ['https://testnet-rpc.monad.xyz'] } },
  testnet: true,
});

export const chogAbi = parseAbi([
  'function tokenURI(uint256 tokenId) view returns (string)',
  'function ownerOf(uint256 tokenId) view returns (address)',
]);

export function ipfsToHttp(uri: string): string {
  return uri.startsWith('ipfs://') ? IPFS_GATEWAY + uri.slice('ipfs://'.length) : uri;
}

export function assertTokenId(id: number): void {
  if (!Number.isInteger(id) || id < 1 || id > CHOG_SUPPLY) throw new RangeError(`Chog token id must be 1-${CHOG_SUPPLY}, got ${id}`);
}

export type MetadataDeps = {
  readTokenURI?: (id: bigint) => Promise<string>;
  fetchJson?: (url: string) => Promise<unknown>;
};

const mainnetClient = createPublicClient({ chain: monad, transport: http() });

const defaultReadTokenURI = (id: bigint) =>
  mainnetClient.readContract({ address: CHOG_CONTRACT, abi: chogAbi, functionName: 'tokenURI', args: [id] });

const defaultFetchJson = async (url: string) => {
  const res = await fetch(url);
  if (!res.ok) throw new Error(`Metadata fetch failed: ${res.status} ${url}`);
  return res.json();
};

export async function fetchChogMetadata(tokenId: number, deps: MetadataDeps = {}): Promise<ChogMetadata> {
  assertTokenId(tokenId);
  const uri = await (deps.readTokenURI ?? defaultReadTokenURI)(BigInt(tokenId));
  const json = (await (deps.fetchJson ?? defaultFetchJson)(ipfsToHttp(uri))) as Partial<{
    name: string;
    image: string;
    attributes: Trait[];
  }>;
  if (typeof json?.image !== 'string' || !Array.isArray(json.attributes)) throw new Error(`Malformed metadata for Chog ${tokenId}`);
  return { tokenId, name: json.name ?? `CHOG #${tokenId}`, image: json.image, attributes: json.attributes };
}
```

`app/src/main/reactions.ts`:
```ts
import type { ArchetypeId, Category } from '@chog/core';
import { LINES } from './lines';

export type Trigger = 'category_switch' | 'long_session' | 'idle_return' | 'late_night' | 'morning' | 'focus_violation' | 'pet';

export type ReactionState = {
  category: Category;
  since: number; // when the current category started
  idleSince: number | null;
  lastSpokeAt: number;
  lastDayGreeted: string;
  lastNightNagged: string;
  longSessionNotified: boolean;
};

export type Observation = { at: number; category: Category; hour: number; day: string };

export const COOLDOWN_MS = 3 * 60_000;
const IDLE_RETURN_MS = 10 * 60_000;
const LONG_SESSION_MS = 90 * 60_000;
const DISTRACTING: Category[] = ['video'];

export function initialState(now: number): ReactionState {
  return { category: 'other', since: now, idleSince: null, lastSpokeAt: 0, lastDayGreeted: '', lastNightNagged: '', longSessionNotified: false };
}

export function detectTrigger(prev: ReactionState, obs: Observation, focusMode: boolean): { trigger: Trigger | null; state: ReactionState } {
  const s = { ...prev };
  const active = obs.category !== 'idle';
  const switched = obs.category !== s.category;

  let returnedFromIdle = false;
  if (!active) s.idleSince ??= obs.at;
  else if (s.idleSince !== null) {
    returnedFromIdle = obs.at - s.idleSince >= IDLE_RETURN_MS;
    s.idleSince = null;
  }
  if (switched) {
    s.category = obs.category;
    s.since = obs.at;
    s.longSessionNotified = false;
  }

  // Priority order. One-time flags are only set when the trigger is actually emitted.
  const candidates: Array<[Trigger, boolean, () => void]> = [
    ['idle_return', returnedFromIdle, () => {}],
    ['focus_violation', focusMode && switched && DISTRACTING.includes(obs.category), () => {}],
    ['morning', active && obs.hour >= 5 && obs.hour < 12 && s.lastDayGreeted !== obs.day, () => (s.lastDayGreeted = obs.day)],
    ['late_night', active && obs.hour < 4 && s.lastNightNagged !== obs.day, () => (s.lastNightNagged = obs.day)],
    ['long_session', active && !s.longSessionNotified && obs.at - s.since >= LONG_SESSION_MS, () => (s.longSessionNotified = true)],
    ['category_switch', switched && active && obs.category !== 'other', () => {}],
  ];
  const hit = candidates.find(([, ok]) => ok);
  if (!hit || obs.at - s.lastSpokeAt < COOLDOWN_MS) return { trigger: null, state: s };
  hit[2]();
  s.lastSpokeAt = obs.at;
  return { trigger: hit[0], state: s };
}

export function pickLine(archetype: ArchetypeId, trigger: Trigger, category: Category, rand: () => number = Math.random): string {
  const options = LINES[archetype][trigger];
  return options[Math.floor(rand() * options.length)].replaceAll('{category}', category);
}
```

export type WalkState = { x: number; dir: 1 | -1; pauseUntil: number };

const SPEED_PX_PER_SEC = 40;
const PAUSE_CHANCE_PER_STEP = 0.003;

export const clampX = (x: number, minX: number, maxX: number) => Math.min(maxX, Math.max(minX, x));

export function stepWalk(s: WalkState, now: number, dtMs: number, minX: number, maxX: number, rand: () => number = Math.random): WalkState {
  if (now < s.pauseUntil) return s;
  if (rand() < PAUSE_CHANCE_PER_STEP) return { ...s, pauseUntil: now + 2000 + rand() * 4000 };
  const x = s.x + s.dir * SPEED_PX_PER_SEC * (dtMs / 1000);
  if (x >= maxX) return { x: maxX, dir: -1, pauseUntil: 0 };
  if (x <= minX) return { x: minX, dir: 1, pauseUntil: 0 };
  return { ...s, x };
}

import { CATEGORIES, type Category, type DailyTotals } from '@chog/core';

export function emptyTotals(): DailyTotals {
  return { minutes: Object.fromEntries(CATEGORIES.map((c) => [c, 0])) as Record<Category, number>, lateMinutes: 0, earlyMinutes: 0 };
}

export function addSample(t: DailyTotals, category: Category, seconds: number, hour: number): DailyTotals {
  const min = seconds / 60;
  const active = category !== 'idle';
  return {
    minutes: { ...t.minutes, [category]: t.minutes[category] + min },
    lateMinutes: t.lateMinutes + (active && (hour >= 22 || hour < 4) ? min : 0),
    earlyMinutes: t.earlyMinutes + (active && hour >= 5 && hour < 8 ? min : 0),
  };
}

export const dayKey = (d: Date) =>
  `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, '0')}-${String(d.getDate()).padStart(2, '0')}`;

import { join } from 'node:path';
import type { DailyTotals } from '@chog/core';
import { dayKey, emptyTotals } from './tally';

export type Settings = { tokenId: number; focusMode: boolean; today: { day: string; totals: DailyTotals } };

const DEMO_TOKEN_ID = 5; // replaced by the signed-in Owner's choice in the integration plan

export function loadSettings(dir: string): Settings {
  const defaults: Settings = { tokenId: DEMO_TOKEN_ID, focusMode: false, today: { day: dayKey(new Date()), totals: emptyTotals() } };
  try {
    return { ...defaults, ...JSON.parse(readFileSync(join(dir, 'settings.json'), 'utf8')) };
  } catch {
    return defaults;
  }
}

  writeFileSync(join(dir, 'settings.json'), JSON.stringify(s, null, 2));

const img = document.getElementById('chog') as HTMLImageElement;

const wrap = document.getElementById('wrap') as HTMLDivElement;

let hideTimer: number | undefined;

window.chog.onInit((p) => {
  img.src = p.image;
  img.title = p.name;
  side = p.side;
});

// Art faces `side`; flip when walking the other way.
window.chog.onFacing((dir) => img.classList.toggle('flip', (dir === 1) !== (side === 'Right')));

window.chog.onSay((text) => {
  bubble.textContent = text;
  bubble.classList.add('show');
  clearTimeout(hideTimer);
  hideTimer = window.setTimeout(() => bubble.classList.remove('show'), 6000);
});

function squash() {
  img.classList.remove('squash');
  void img.offsetWidth; // restart animation
  img.classList.add('squash');
}

// Drag vs click: movement over 4px means drag.
let down: { x: number; y: number } | null = null;
let dragging = false;
wrap.addEventListener('pointerdown', (e) => {
  down = { x: e.screenX, y: e.screenY };
  dragging = false;
  wrap.setPointerCapture(e.pointerId);
});
wrap.addEventListener('pointermove', (e) => {
  if (!down) return;
  if (!dragging && Math.hypot(e.screenX - down.x, e.screenY - down.y) > 4) {
    dragging = true;
    window.chog.dragStart();
  }
  if (dragging) window.chog.dragMove(e.screenX, e.screenY);
});
wrap.addEventListener('pointerup', () => {
  if (dragging) window.chog.dragEnd();
  else window.chog.petClick();
  squash();
  down = null;
  dragging = false;
});

```ts
import { app, BrowserWindow, dialog, ipcMain, screen } from 'electron';
import path from 'node:path';
import { fetchChogMetadata, ipfsToHttp, type ChogMetadata } from '@chog/core';
import { clampX, stepWalk, type WalkState } from './walker';
import { loadSettings } from './store';

const W = 160;
const H = 190;
const TICK_MS = 50;

let win: BrowserWindow | null = null;
let walk: WalkState = { x: 0, dir: 1, pauseUntil: 0 };
let dragging = false;
let dragOffset = { x: 0, y: 0 };

if (!app.requestSingleInstanceLock()) app.quit();
app.dock?.hide();

async function loadChog(tokenId: number): Promise<ChogMetadata> {
  let lastErr: unknown;
  for (let i = 0; i < 3; i++) {
    try {
      return await fetchChogMetadata(tokenId);
    } catch (e) {
      if (e instanceof RangeError) throw e;
      lastErr = e;
      await new Promise((r) => setTimeout(r, 2000));
    }
  }
  throw lastErr;
}

function workAreaFor(x: number, y: number) {
  return screen.getDisplayNearestPoint({ x: Math.round(x), y: Math.round(y) }).workArea;
}

function groundY(area: Electron.Rectangle) {
  return area.y + area.height - H;
}

async function start() {
  const settings = loadSettings(app.getPath('userData'));
  const tokenId = Number(process.env.CHOG_TOKEN_ID ?? settings.tokenId);

  let meta: ChogMetadata;
  try {
    meta = await loadChog(tokenId);
  } catch (e) {
    dialog.showErrorBox('Chog Buddy', `Could not load Chog #${tokenId}.\n\n${(e as Error).message}`);
    app.quit();
    return;
  }

  const area = screen.getPrimaryDisplay().workArea;
  walk = { x: area.x + area.width / 2, dir: 1, pauseUntil: 0 };

  win = new BrowserWindow({
    width: W,
    height: H,
    x: Math.round(walk.x),
    y: groundY(area),
    transparent: true,
    frame: false,
    resizable: false,
    skipTaskbar: true,
    hasShadow: false,
    focusable: false,
    webPreferences: { preload: path.join(__dirname, 'preload.cjs') },
  });
  win.setAlwaysOnTop(true, 'screen-saver');
  win.setVisibleOnAllWorkspaces(true, { visibleOnFullScreen: true });
  await win.loadFile(path.join(__dirname, 'index.html'));
  const side = meta.attributes.find((a) => a.trait_type === 'Side')?.value === 'Left' ? 'Left' : 'Right';
  win.webContents.send('init', { image: ipfsToHttp(meta.image), side, name: meta.name });

  let last = Date.now();
  setInterval(() => {
    const now = Date.now();
    const dt = now - last;
    last = now;
    if (!win || dragging) return;
    const [, curY] = win.getPosition();
    const a = workAreaFor(walk.x, curY);
    const prevDir = walk.dir;
    walk = stepWalk({ ...walk, x: clampX(walk.x, a.x, a.x + a.width - W) }, now, dt, a.x, a.x + a.width - W);
    if (walk.dir !== prevDir) win.webContents.send('facing', walk.dir);
    win.setPosition(Math.round(walk.x), groundY(a));
  }, TICK_MS);
}

ipcMain.on('drag-start', () => {
  if (!win) return;
  dragging = true;
  const p = screen.getCursorScreenPoint();
  const [x, y] = win.getPosition();
  dragOffset = { x: p.x - x, y: p.y - y };
});
ipcMain.on('drag-move', (_e, p: { x: number; y: number }) => {
  win?.setPosition(Math.round(p.x - dragOffset.x), Math.round(p.y - dragOffset.y));
});
ipcMain.on('drag-end', () => {
  if (!win) return;
  const [x, y] = win.getPosition();
  const a = workAreaFor(x, y);
  walk = { ...walk, x: clampX(x, a.x, a.x + a.width - W) };
  win.setPosition(Math.round(walk.x), groundY(a)); // drop to the ground
  dragging = false;
});

app.whenReady().then(start);
app.on('window-all-closed', () => app.quit());
```
