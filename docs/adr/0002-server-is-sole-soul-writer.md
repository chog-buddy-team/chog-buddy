# One server wallet writes all Souls

`ChogSoul` accepts writes only from a single server-held key, which batches every Chog's daily Drift into one transaction. This means Owners never pay gas or sign transactions after sign-in. The cost is centralization: whoever holds the key can set any Soul. Accepted for the hackathon on Monad testnet with a testnet-only key. Moving to Owner-signed or attested updates is future work.
