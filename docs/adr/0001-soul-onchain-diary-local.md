# Soul is public and onchain; Diary is private and local

A Chog's character is split in two. The Soul (Axes, Level, Owner Count) is written onchain against the token ID and transfers with the Chog, so the NFT itself carries a history and stays essential to the experience. The Diary holds details of the Owner's real life. It is generated by the server but stored only on the Owner's machine, never persisted server-side, and wiped when the Owner no longer holds the Chog. We rejected passing full memory to the next owner because of privacy. We rejected resetting everything on transfer because then the NFT would add nothing a plain sprite couldn't.

## Consequences

Never add Diary text, window titles or raw Activity to the Soul or to any server table. The Soul may only contain coarse numbers derived from Category durations.
